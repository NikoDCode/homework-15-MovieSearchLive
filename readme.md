# MovieSearchLive

LiveSearch-приложение для поиска фильмов с использованием OMDb API

## Описание проекта

Данное веб-приложение позволяет пользователям искать фильмы в реальном времени, используя OMDb API. По мере ввода поискового запроса результаты поиска автоматически отображаются на странице без необходимости нажатия кнопки "Поиск".

## Функциональные возможности

- **Живой поиск**: Результаты обновляются автоматически во время ввода запроса
- **Интеграция с OMDb API**: Получение актуальных данных о фильмах из открытой базы данных
- **Отображение постеров**: Каждый результат поиска включает в себя постер фильма и основную информацию
- **Опция накопления результатов**: Возможность добавлять новые результаты поиска к уже существующим
- **Динамическая генерация контента**: Вся страница создается с использованием JavaScript

## Технологии

- HTML5
- CSS3
- JavaScript (ES6+)
- OMDb API

## Как использовать

1. Введите название фильма в поле поиска (минимум 4 символа)
2. Подождите около 2 секунд - результаты поиска появятся автоматически
3. Установите флажок "Добавлять фильмы к уже существующему списку", если хотите сохранить предыдущие результаты поиска

## API ключ

В проекте используется API ключ для OMDb API. Текущий ключ встроен в код, но для продакшн-версии рекомендуется получить собственный ключ на [официальном сайте OMDb API](https://www.omdbapi.com/).

## Структура проекта

- `index.html` - основная HTML структура
- `style.css` - стили для приложения
- `index.js` - логика приложения
- `img/no-image.png` - изображение-заполнитель для фильмов без постеров

## Особенности реализации

- Задержка поиска (debounce) в 2 секунды для уменьшения нагрузки на API
- Минимальная длина поискового запроса - 4 символа
- Автоматическая валидация URL постеров
- Обработка ошибок при некорректных данных от API
